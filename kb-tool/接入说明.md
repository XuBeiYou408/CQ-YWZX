# 企业本地知识库 - WorkBuddy MCP Tool 接入说明

## 一、MCP Server 已就绪

启动命令（WorkBuddy 会自动拉起，无需手动运行）：
  C:\Users\ABC\Desktop\123\知识库tool版\.venv\Scripts\python.exe mcp_server.py

## 二、在 WorkBuddy 中接入

1. 打开 WorkBuddy 设置 → "MCP 服务" 或 "工具管理" → "添加自定义 MCP"
2. 填写以下信息：
   - 名称：enterprise-knowledge-base
   - 启动命令：C:\Users\ABC\Desktop\123\知识库tool版\.venv\Scripts\python.exe
   - 参数：C:\Users\ABC\Desktop\123\知识库tool版\mcp_server.py
   - 环境变量：PYTHONIOENCODING=utf-8  PYTHONUNBUFFERED=1

   或者直接导入配置文件（如果 WorkBuddy 支持 JSON 导入）：
   C:\Users\ABC\Desktop\123\知识库tool版\workbuddy_mcp_config.json

## 三、WorkBuddy 对话示例

接入后，您可以直接用自然语言向 WorkBuddy 提问：

  "公司差旅报销标准是什么？"
  "年假申请流程怎么走？"
  "帮我看一下知识库里有哪些文件"
  "把桌面上的员工手册.pdf 加入知识库"

WorkBuddy 会自动识别并调用以下三个工具：

  - search_knowledge_base     → 混合语义检索（向量+BM25+重排）
  - list_knowledge_documents  → 列出所有已收录文档
  - add_document_to_knowledge → 新增并索引文档（传本地绝对路径）

## 四、扩充知识库

将新文档（pdf/docx/md/txt）放入以下目录，下次检索时自动重建索引：
  C:\Users\ABC\Desktop\123\知识库tool版\data\documents\

或在 WorkBuddy 中说：
  "把 D:\公司文件\采购制度2026.pdf 加入知识库"

## 五、注意事项

- 知识库文档与向量索引存放在本机 data\ 目录，数据完全私有不上传
- BGE 嵌入模型在本地离线运行，无需联网（首次启动约 3~8 秒预热）
- 大模型推理（生成答案环节）需要 LM Studio 本地服务或 .env 中配置 DEEPSEEK_API_KEY
