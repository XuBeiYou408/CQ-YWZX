# SalesAgent v2.0 · 企业销售战区督导与业绩尽调复合智能体

面向企业销售管理与决策层的企业级销售战区智能参谋驾驶舱。全面对标「简历筛查」优秀架构范式，升级为**「双层漏斗复合智能体（Two-Stage Funnel Compound Agent）」**与**「SQLite 强闭环数据持久化」**工业级架构。不仅提供“100% 确定性算术层 + 认知提炼层”双轨引擎，更引入**L1 极速守门员**与**L2 ReAct 战区总参谋长**，内嵌四维督导工具链穿透业绩真实性、断崖风险与卡单死穴，全面赋能销售主管战略决策。

---

## 🌟 核心功能与架构亮点

### 1. 🛡️ 双层漏斗复合智能体架构 (Two-Stage Funnel)
- **L1 极速合规与数据守门员 (0 Token 毫秒硬过滤)**：
  - 毫秒级硬性拦截字段缺失、负数回款、拜访逻辑冲突与关键信息空缺，不耗费任何 LLM Token。
- **L2 战区总参谋长 ReAct 复合智能体 (自主状态机循环)**：
  - 遵循「感知 (Perceive) → 规划 (Plan) → 工具调用 (Act) → 综合反思定案 (Reflect)」闭环工作流；
  - 交叉调用 4 大专业督导工具链展开深度尽调，并生成 13+ 步完整调查轨迹思维链。

### 2. 🧰 四维销售督导行动层工具链 (Agent Tools)
1. **商机水分剥离与虚词测谎 (`deal_substance_evaluator`)**：
   - 智能识别并剔除“正在走流程”、“客户意向强烈”、“领导原则上同意”等模糊推诿套话；
   - 深度穿透核验资金到账、法务主合同盖章、KP高层决策链攻坚等硬核客观凭证，测算成单真实脱水得分。
2. **商机漏斗蓄水与断崖预测 (`pipeline_cliff_predictor`)**：
   - 交叉比对当期达成率与客户拜访频次、新增储备线索，前瞻预警未来 2-4 周业绩断崖式下行风险。
3. **卡单死穴定性与归因溯源 (`blocker_root_cause_tracer`)**：
   - 智能归因体制换届停滞、竞品恶意低价 40% 围标、法务交付违约金争端等深层组织与商务死穴，标注是否需要主管紧急介入。
4. **主管靶向派工与攻坚锦囊 (`tactical_dispatch_generator`)**：
   - 点对点生成高管亲自陪访公关、法务补充协议口径、售前技术专家资源空投等定制化破局战术锦囊。

### 3. 🔬 AI 销售战区经营全景动态诊断引擎 (方案 B 看板)
- **战区经营健康分 (0 - 100)**：动态加权全员达成率、真实置信度与风险暴露率，实时反映大盘经营质量。
- **大盘业绩真实置信度**：基于全员尽调脱水后的真实置信度动态均值。
- **暴雷/卡单风险暴露率**：高亮大盘重大卡点异动比例。
- **4 维宏观战略管理推演清单**：提炼【标杆战法复制】、【卡单止血排雷】、【商机蓄水扩容】、【高管资源协同】实战指令，支持实时重新推演并持久化。

### 4. 🗄️ SQLite 工业级数据持久化与强闭环体系
- **单文件落盘至 `data/sales_reports.db`**：Python 原生标准库实现，零额外 pip 依赖，开启 **WAL (Write-Ahead Logging)** 预写日志与单例写锁保护。
- **全生命周期数据落盘**：
  - 上传周报台账、主管批阅评语、ReAct 智能体尽调档案、思维链轨迹、决策内参与动态推演全部落盘；
  - **服务重启数据 100% 完整留存**，彻底解决重启数据清空丢失问题。
- **四维数据逻辑强一致**：周报明细台账、团队聚合指标、每周决策内参、大盘动态诊断实时联动，杜绝逻辑脱节。
- **单事务级联原子重置 (`POST /api/reports/reset`)**：一键原子清空并回滚至标准 4 人标杆基线，无任何孤儿残留。

### 5. 📑 仿真 A4 双标签页原件抽屉与思维链检视
- **标签页 1：🕵️ AI 战区参谋长尽调档案与思维链**：
  - 终审裁决大看板与置信度进度条；
  - 四维行动层工具交叉取证卡片 (2x2 Grid)；
  - 可折叠展开的完整 ReAct 探查时间线与思维链日志 (Dark 极客风格)；
  - 支持单人「🔄 重新触发 ReAct 尽调」。
- **标签页 2：📄 100% 原始提交周报原件**：
  - 仿真 A4 纸质排版，还原销售提交的原始排版与全部细节，支持一键下载原件。

### 6. 📊 确定性算术指标大盘与所见即所得导出
- 100% 原生 Python 算术核算（防大模型数字幻觉），梯队互斥分类。
- 支持批量解析导入 `.docx`, `.xlsx`, `.md`, `.txt` 等多源格式。
- 一键导出标准格式企业级 Word (`.docx`) 周报台账与 Markdown (`.md`) 决策内参。

## 🚀 快速启动与自举说明

### 1. 前置条件与环境
- **Python 环境**：建议 **Python 3.11 – 3.13**（安装时勾选 `Add Python to PATH` 与 `py launcher`）。
- **大模型支持**：
  - 本地优先：后台启动 **LM Studio**（默认端口 `1234`，模型推荐 `qwen3.8-27b`）；
  - 云端支持：在工作台右上角「模型设置」填入云端 API Key（DeepSeek、通义千问等），支持在线测速；
  - 自动降级：若脱网或未启动本地模型，系统自动无损降级为高保真确定性内参，保障业务 100% 可用。

### 2. 双击自举启动 (推荐)
- 双击运行根目录下的 **`一键启动.bat`**。
- **自举流程**：
  1. 自动调用 Python 解释器并自检依赖；
  2. 自动创建与加载专属独立虚拟环境 `.venv`；
  3. 自动幂等初始化 SQLite 数据库（`data/sales_reports.db`）并播种初始基线；
  4. 自动拉起服务并唤起默认浏览器：`http://127.0.0.1:8040`。
