# SalesAgent · 企业销售周报自动汇总智能体

面向企业销售管理与决策层的本地化销售周报自动汇总智能体。支持销售人员提交的多格式周报自动解析入库，提供**“确定性算术层 + 认知提炼层”**双轨架构，支持销售主管全屏查阅销售提交的 100% 原始原件文档，一键生成战略级管理决策内参，并支持标准 Word (`.docx`) 与 Markdown 格式导出。

---

## 🌟 核心功能特性

1. **确定性算术指标大盘 (100% Python Code 精确计算)**
   - 杜绝大模型数字幻觉与算术错误，签约总额、达成率、回款额、客拜总量、龙虎榜由原生代码严密核算。
   - 实时四维数据看板：部门总签约 (带进度条)、实际总回款、客拜与在途商机、销售梯队状态分布。

2. **销售原始周报原件检视抽屉 (原版 100% 还原)**
   - 专为销售主管设计，点击任意销售卡片「查看原始周报原件」，即可调出仿真 A4 纸质感的完整原版周报检视器。
   - 完整展示销售人员实际填写的明细数据、商机推进、阻碍求助及下周排期，并支持直接下载原始文档。

3. **战略级销售决策内参 (本地 LM Studio / 云端 LLM 驱动)**
   - **部门经营态势综述**：客观评述全员目标达成态势与回款效率。
   - **核心战报突破 (Highlights)**：提炼重大签约、KA 标杆攻坚经验。
   - **风险雷达 (Risk & Blockers)**：高亮丢单预警、央企换届停滞、竞品低价恶意倾销等重大阻碍。
   - **主管派工行动清单 (Action Plan)**：点对点给出销售主管下周介入督导、跨部门资源协同派工指令。

4. **主管手动修订与闭环导出**
   - 支持主管就地修改润色内参报告，一键保存至系统。
   - 一键下载排版严谨的标准企业级 Word 周报 (`.docx`，包含大盘汇总表与主管批阅台账)。
   - 一键复制格式清晰的 Markdown 周报全文至剪贴板，便于粘贴至企业微信/钉钉。

5. **多源多格式周报批量解析导入**
   - 支持批量拖拽或选择上传 `.docx`, `.xlsx`, `.md`, `.txt` 格式的销售周报，智能识别指标字段并无缝合并计算。

6. **端云双模统一适配器**
   - 支持本地 LM Studio (1234 端口 `qwen3.8-27b`) 毫秒级在线探测。
   - 支持一键切换至 DeepSeek、通义千问等云端大模型，支持 API Key 在线测速。

## 🚀 快速启动与自举说明

### 1. 前置条件与环境
- **Python 环境**：建议 **Python 3.11 – 3.13**（安装时勾选 `Add Python to PATH` 与 `py launcher`）。
- **大模型推理**：后台启动 **LM Studio**（默认端口 `1234`，模型推荐 `qwen3.8-27b`），或在工作台右上角配置云端 API Key。

### 2. 双击自举启动 (推荐)
- 双击运行项目根目录下的 **`一键启动.bat`**。
- **自举特性**：优先调用 `py -3`，自动为销售周报创建专属 `.venv` 虚拟环境并安装 `requirements.txt`（包含 `openpyxl`, `python-docx`, `python-multipart`, `FastAPI` 等）；
- 自动自检端口 `8040` 与模型连通性，并在默认浏览器中自动打开工作台：`http://127.0.0.1:8040`。
- 具备严格幂等性，日常反复双击秒级启动。
