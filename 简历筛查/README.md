# RecruitAI · 企业智能招聘与简历初筛智能体

本系统是基于**方案一（轻量化纯端侧自主构建架构）**打造的第三个独立演示项目：**“招聘简历筛查智能体：自动筛查符合岗位JD要求的求职者”**。

界面设计**严格 1:1 像素级复刻 Google Stitch 官方项目（`projects/4347107337271112305`）PC 桌面端（Screen ID: `2c07daf559fc47f18acdaa66573c6e15`）**的 `Kinetic Emerald Workdesk` 视觉体系（翠绿 `#00B395` + 亮薄荷 `#00C5A8` + AI紫 `#5039f6`）。

---

## 🌟 核心特色与技术亮点

1. **轻量纯端侧架构 (Zero Docker / Zero Cloud)**：
   - 彻底摒弃原开源项目中繁杂的 5 大 Docker 数据库集群（MySQL, Redis, MinIO, ChromaDB 等）与云端强绑定。
   - 纯原生 Python 3.14 + FastAPI + 现代响应式单页架构，单端口（8030）开箱即用。

2. **双模多模型引擎（端云协同）**：
   - **本地自动感知**：系统启动自检，自动优先命中本地已跑通的 LM Studio（`http://127.0.0.1:1234/v1`，模型 `qwen3.8-27b`）或 Ollama；
   - **云端无缝接入**：顶栏内置动态状态胶囊，支持在工作台直接一键切换至 **DeepSeek (V3/R1)**、**通义千问 (DashScope)**、**月之暗面 (Kimi)** 等主流商用大模型，自带连通性与延迟测试。

3. **双轨初筛决策算法**：
   - **Track 1: 硬性门槛规则引擎**：智能抽取学历层级、院校层次（985/211标识）、工作经验年数与核心技能；不达标自动拦截、标记具体违规原因并限制分数。
   - **Track 2: LLM 深度语义打分**：分析技术深度、架构规模与岗位契合度，生成 S/A/B/C 评级、五维拟合度雷达数据、AI 甄选深度评语，以及**3道针对履历薄弱点的定制面试追问**。

4. **开箱即用 + 任意真实简历现场随心测**：
   - 内置 Stitch 设计稿 4 位典型候选人（S级98%极高推荐-林远志、A级91%业务契合-陈书廷、76%需人工复核-赵晨浩、45%硬性门槛拦截-张铭），一启动就有饱满真实的数据看板；
   - 支持现场随时拖拽上传任意真实求职者简历（支持 `.pdf`, `.docx`, `.txt`, `.md`），调用本地 PyMuPDF/python-docx 即时解析初筛并动态加入看板。

## 🚀 极速启动与前置条件

### 1. 前置条件与环境说明
- **Python 环境**：建议 **Python 3.11 – 3.13**（安装时请勾选 `Add Python to PATH` 以及 `Install launcher for all users (py)`）。
- **推理大模型**：后台启动 **LM Studio**（默认端口 `1234`，模型推荐 `qwen3.8-27b`），或在工作台右上角模型胶囊中配置云端 API Key（DeepSeek / 通义千问等）。

### 2. 双击自举启动 (推荐)
直接在资源管理器中双击根目录下的 **`一键启动.bat`**：
- 脚本将优先使用 `py -3` 解释器；
- 首次运行自动为简历筛查创建独立的 `.venv` 虚拟环境，并自动安装所有依赖（包含 `fastapi`, `pymupdf`, `python-multipart`, `python-docx`, `httpx` 等）；
- 自动自检端口 `8030` 并唤起默认浏览器打开工作台：**`http://127.0.0.1:8030`**。
- 支持幂等反复双击，日常使用秒级启动。

### 3. 命令行启动
```bash
cd 简历筛查
.venv\Scripts\python run.py
```

## 🖥️ 现场演示剧本推荐

1. **宏观看板总览**：
   - 观察顶部导航的 RecruitAI 品牌标识、岗位横幅与 4 维核心数据看板（总投递、待复核、高推荐、已约面）。
2. **Tab 与多状态流转**：
   - 切换“全部投递”、“AI极高推荐”、“待人工复核”、“已约面”、“淘汰拦截库”；
   - 观察候选人卡片左侧具有设计感的流光指示条（S级紫绿渐变、A级翠绿、复核灰、拦截红）。
3. **深入候选人画像与定制面试题**：
   - 点击“林远志”卡片的“查看简历”，打开右侧抽屉，展示五维拟合度水平条、AI甄选理由与针对千万级并发经验的3道追问题目。
4. **演示门槛拦截机制**：
   - 切换到“淘汰/拦截库”，查看“张铭”卡片，系统清晰标明了拦截原因：“年限1年(要求5年+)”、“大专学历(要求统招本科)”。
5. **现场上传真实简历初筛**：
   - 点击顶部“上传简历”，拖入任意一份 `.pdf` 或 `.docx` 简历，点击“开始初筛”，观察 AI 实时解析打分并呈现在列表中。
6. **多模型端云切换**：
   - 点击右上角绿色模型胶囊，向观众展示本地端侧 LM Studio 的实时在线状态与超低延迟；同时展示支持输入 Key 一键无缝切到 DeepSeek 云端大模型的能力。
