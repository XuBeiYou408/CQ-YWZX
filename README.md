# CQ-YWZX 项目合集仓库

本项目仓库用于集中归档与管理相关企业级业务智能体系统及核心交付模块。全部子工程均已完成从传统脚本/单步工作流向**「自主 Agent / 复合智能体」**深度架构演进。

---

## ⚙️ 全局运行环境与自举式架构规范

- **Python 运行环境要求**：**建议 Python 3.11 – 3.13**（推荐从 [python.org](https://www.python.org/downloads/) 下载官方安装包，安装时务必勾选 **`Add Python to PATH`** 与 **`py launcher`**）。
- **自举式一键启动 (Self-Bootstrapping)**：
  - 各项目**完全独立、物理隔离、互不依赖**，各自在项目目录下维护专属的 `.venv` 虚拟环境与 `requirements.txt`。
  - 在全新克隆的代码库中，直接双击各项目目录下的 **`一键启动.bat`**，脚本将优先调用 `py -3`（防御微软商店假占位符），自动创建当前项目的 `.venv`、自动安装完整依赖并拉起服务。
  - 脚本具备**严格幂等性**，后续日常使用双击可秒级启动，无需重复安装依赖。

## 🔐 仓库数据边界（隐私与运行时数据不入库）

本仓库**只收录源码、文档与演示用测试数据**。下列运行时数据一律不入库（已在 `.gitignore` 中排除），
它们由应用自动创建，或在首次启动时以代码内预置数据 / 默认配置重建：

| 不入库内容 | 所在项目 | 说明与重建方式 |
| :--- | :--- | :--- |
| `data/store.json` | 简历筛查 | 候选人库、面试日程、微聊记录、**上传的简历原文**。首次启动自动以 `app/core/presets.py` 预置数据生成 |
| `config.json` | 简历筛查 / 销售周报 | 运行时配置；**界面里填入的云端 api_key 会写入此文件**。缺失时自动以默认配置生成 |
| `data/sales_reports.db` | 销售周报 | SQLite 销售台账（含真实客户与金额）。启动时自动初始化并播种基线 |
| `uploads/`、`exports/` | 简历筛查 / 销售周报 | 上传的原始附件、以及 Word/Markdown 导出产物 |
| `.env` | 企业本地知识库 / kb-tool / 合同审查 | 真实云端密钥。脱敏范本 `.env.example` 已保留 |
| `data/models/`、`data/faiss_db/` | 企业本地知识库 / kb-tool | BGE 模型权重（约 400MB）与 FAISS 索引；首次检索时自动下载 / 重建 |

**保留在仓库中的数据**（属项目内容与可公开的测试数据）：企业知识库的制度文档
（`data/documents/`，为通用示例模板）、合同审查的条款与风险规则字典
（`contract/data/*.csv`）、以及各项目内置的演示预置数据（`app/core/presets.py`）。
因此 `git clone` 后即可直接启动，无需额外准备数据。

## 📋 各项目前置条件与运行指引

每个子项目均为独立自治工程，请查阅对应项目目录下的 `README.md` 与前置配置：

### 1. [企业本地知识库](./企业本地知识库) (端口: `8010`)
- **核心架构**：动态 LLM 工厂 + ReAct 自主规划环 + 混合检索 (Dense + Sparse) + 独立 Session 隔离。
- **前置条件与系统要求**：
  - **Python**：建议 3.11 – 3.13。
  - **Node.js 环境**：前端基于 Vue 3 + Vite 构建（**未附带 `dist` 构建产物**，首次使用需 `cd frontend && npm install && npm run build` 生成后再启动）。
  - **嵌入与重排模型**：依赖 BGE 向量模型（`BAAI/bge-large-zh-v1.5` 与 `bge-reranker-large`），启动时通过镜像源自动缓存。
  - **大模型支持**：后台需启动 LM Studio（默认端口 `1234`）或在工作台右上角切换并填入云端 API Key（如 DeepSeek）。
- **启动方式**：进入 `企业本地知识库/` 目录，双击运行 **`一键启动.bat`**。

### 2. [合同审查 AGENT](./合同审查) (端口: `8020`)
- **核心架构**：四阶段自主 Agent 状态机 + 条款级分诊器 (`planner.py`) + OOXML Lite 原生 Word 修订引擎。
- **前置条件与系统要求**：
  - **Python**：建议 3.11 – 3.13。
  - **依赖管理**：双击 `一键启动.bat` 自动自举创建 `.venv` 并补全安装所有依赖（含 PyMuPDF、python-multipart、python-docx、FastAPI 等）。
  - **大模型支持**：后台启动 LM Studio 并开启 Local Server（默认 `http://127.0.0.1:1234/v1`），或在工作台右上角切换并配置云端 API Key。
- **启动方式**：进入 `合同审查/` 目录，双击运行 **`一键启动.bat`**。

### 3. [RecruitAI 简历初筛与深度尽调智能体](./简历筛查) (端口: `8030`)
- **核心架构**：两段式漏斗复合智能体（L1 规则守门员 + L2 资深猎头 ReAct 状态机）+ 门槛变更联动人才公海自动召回 + 全量数据原子持久化落盘 (`data/store.json`) 与开机自愈校验 + 方案 B 真实数据宏观全景动态诊断。
- **前置条件与系统要求**：
  - **Python**：建议 3.11 – 3.13。
  - **数据存储**：内置无依赖轻量级持久化存储引擎（开箱即用，重启不丢状态，支持 `/api/reset` 一键恢复演示出厂）。
  - **依赖管理**：双击 `一键启动.bat` 自动自举创建 `.venv` 并补齐依赖（含 python-multipart、PyMuPDF、FastAPI、httpx 等）。
  - **大模型支持**：本地 LM Studio (`qwen3.8-27b`) 或在工作台模型设置弹窗中填入云端 API Key (DeepSeek / 通义千问 / Kimi 等)。
- **启动方式**：进入 `简历筛查/` 目录，双击运行 **`一键启动.bat`**。

### 4. [SalesAgent 销售战区督导与业绩尽调复合智能体](./销售周报) (端口: `8040`)
- **核心架构**：两段式漏斗复合智能体（L1 极速守门员 + L2 ReAct 战区参谋长状态机）+ 4维督导工具链 + SQLite 工业级持久化强闭环 + 方案 B 战区全景动态诊断 + 仿真 A4 双标签页抽屉。
- **前置条件与系统要求**：
  - **Python**：建议 3.11 – 3.13。
  - **数据存储**：内置轻量级 SQLite 数据持久化（`data/sales_reports.db`，开箱即用无须额外安装配置数据库）。
  - **依赖管理**：双击 `一键启动.bat` 自动自举创建 `.venv` 并补全安装所有依赖（含 openpyxl、python-docx、python-multipart、FastAPI 等）。
  - **大模型支持**：本地 LM Studio (`qwen3.8-27b`) 或云端大模型热切换（具备高保真确定性兜底保障）。
- **启动方式**：进入 `销售周报/` 目录，双击运行 **`一键启动.bat`**。
