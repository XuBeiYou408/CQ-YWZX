## 🚀 模块运行指引

各子项目均为独立自治的工程模块，请进入对应子项目目录查看专属运行文档与启动脚本：

- **企业本地知识库**：进入 [企业本地知识库/](./企业本地知识库) 目录，双击运行 一键启动.bat 即可一键拉起后端 API 与前端 SPA 界面（端口：8010）。
- **合同审查 AGENT**：进入 [合同审查/](./合同审查) 目录，双击运行 一键启动.bat 即可一键拉起审查服务并自动唤起浏览器（端口：8020）。确保后台已启动 LM Studio 本地模型服务。
- **RecruitAI 简历初筛智能体**：进入 [简历筛查/](./简历筛查) 目录，双击运行 一键启动.bat 即可一键拉起工作台并自动唤起浏览器（端口：8030）。支持本地 LM Studio (qwen3.8-27b) 与 DeepSeek / 通义千问等云端模型无缝切换。
